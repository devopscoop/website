Kubernetes

Essential CLI tools for working with Kubernetes clusters.

  • kubectl — The Kubernetes command-line tool. Install kubectl →
  • krew — The kubectl plugin manager. Install krew →
    • kubectl-netshoot — Spin up a netshoot container for in-cluster network troubleshooting. Requires krew. Add the index and install: 
      kubectl krew index add netshoot https://github.com/nilic/kubectl-netshoot.git
kubectl krew install netshoot/netshoot
      kubectl-netshoot on GitHub →
  • k9s — Terminal-based UI for managing clusters. Install k9s →
  • stern — Multi-pod log tailing with color-coded output. Install stern →
  • Helm — Package manager for Kubernetes. Install Helm →
  • Kustomize — Kubernetes-native configuration management. Install Kustomize →
  • jq — Command-line JSON processor. Install jq →
  • yq — Command-line YAML processor. Install yq →
